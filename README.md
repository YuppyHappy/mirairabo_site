# my-org-site

Astro 7 + Tailwind CSS v4 + Motion による静的 LP です。

## セットアップ

```powershell
npm install
npm run dev
```

## ビルド

```powershell
npm run check
npm run build
```

## デプロイ（Vercel）

1. GitHub に push
2. Vercel でリポジトリを Import
3. Framework Preset: Astro
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Node.js Version: 22.x

## データ更新

- 活動報告: `src/content/reports/*.md`
- イベント: `src/content/events/*.json`
- サイト情報・フォーム URL: `src/data/site.ts`
```
